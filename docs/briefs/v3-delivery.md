# 小咪工具箱 V3.0 交付与验收

2026-11-25。本地 V3.0 已实现，发布仍有门槛。微信连接的业务数据库需要在明确的测试环境完成迁移和登录回归。开发基线是 `ff94405`，页面历史截图来自 11 月 25 日的既有验收。 [工程交接](v3-engineering.md) · [历史截图](../screenshots/2026-11-25-full/REPORT.md)

## 产品与实现

- 首页优先显示家庭风险和录入。库存使用独立搜索、可展开筛选和品类分组。用药优先显示今日任务。我的采用设置分组和统一导出入口。九个二级页面同步更新表单、列表、加载或错误反馈。
- 会话校验共享进行中的请求，临时认证故障保持可重试状态。退家与管理员移除撤销家庭访问，并保留受影响成员和既有用药记录。
- 物品、首批库存及入库流水同事务保存。回收站恢复区分级联批次和独立移入批次。开封、用完、报废使用条件写入与状态约束。对数量或计量单位存在冲突的库存显示待核对。
- 用药确认按服药人检查登记关联。计划版本检查、事务和重试编号共同保护保存及取消，过敏状态暂不可核对时客户端暂停确认。依从性统计以已确认和标记漏服为分母。时区、漏服阈值和旧计划残留场次的处理见工程交接。

## 验证与性能

| 验证 | 结果 |
| --- | --- |
| `npm test` | 静态检查 128 项通过。会话、库存、用药、首页、我的、导出和回收站专项通过 |
| 本地 PostgreSQL | PGlite 0.6.0 内存库用合成成员和库存验证 SQL 08–11 重跑，覆盖跨家庭读隔离、退出与重入、用药拦截与保存重试、库存原子录入与回收站。使用单连接验证状态和版本断言 |
| 本机并发与恢复 | PostgreSQL 17.12 上用两个真实连接观察并发等待。重复入库成功复用结果，并发编辑中旧版本被拒绝。复跑漏服语句验证 29／30／31 分钟边界，停库快照恢复后核对合成数据和服药写权限 |
| 渲染与视觉对照 | 直接调用微信开发者工具采集当前小程序画面。截图内容、方法和覆盖见截图索引。 [截图索引](../screenshots/v3-runtime/README.md) |
| 首页查询量 | 按相同小数据场景源码估算，从约 12 次页面读取降到约 7 次。分页、空数据会改变次数，认证和传输重试另计 |
| 本地打包输入估算 | 按各版本 `packOptions.ignore` 统计 Git `ff94405` 与 `e27b195`，不计生成的 npm 内容，1,106,575 B → 1,182,928 B。资源 756,925 B → 826,699 B，约增加 9.2%，已含首批 12 张新增产品图。本机共用的 `miniprogram_npm` 构建目录为 170,238 B。配置未启用分包 |
| 微信开发者工具 | 当前 13 页 WXML 与 WXSS 共 26 项编译通过。当前连接的云环境下复用已登录会话，只读确认首页风险与我的基础资料能加载。库存缺少 `members.left_at`，用药计划进入重试状态。库存提示已通过专项回归，开发者工具的提示重测遇到连接重置和超时。目标云端迁移完成前需保留发布阻塞 |
| 实机耗时、网络与日志 | 没有同账号、同数据的前后计时、网络轨迹和控制台异常基线。源文件字节数与查询估算用于定位改动收益，微信实际压缩包和耗时留待隔离环境复测 |

本轮按模块由三位子 Agent 并行负责库存与录入、用药与档案、首页与家庭设置。主 Agent 集成会话、数据库、图片、模拟器验收，子 Agent 交叉复核接口和权限。使用 Apple Design 检查层级、分组列表和触控目标，使用 Ponytail 保持原生组件和现有数据契约，使用 Image Gen 完成角色素材。 [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/)

## 发布门槛

- 确认专用 WorkBuddy 测试库、备份和实际迁移角色授权，在同一连接按顺序迁移，验证认证角色、PostgREST 缓存、定时任务和双客户端并发。
- 完成真实登录后的家人管理、横向权限、导出分享、库存与用药写入回归；真机验证扫码、摄像头、微信授权、窄屏和读屏。
- 使用同一设备及数据集测首页、用药计划加载中位数与实际小程序包。旧版写入与 V3 迁移的直接写权限不兼容，切换按工程交接协调。 [工程交接](v3-engineering.md)
